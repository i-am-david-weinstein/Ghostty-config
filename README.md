CONFIG SETUP
============
1) Clone repo (suggested directory: `~/.config/ghostty/`)
2) Launch Ghostty, or reload a running one with `Cmd+Shift+,`
3) Optional: check the config with `ghostty +validate-config`
4) Done!

NOTES
=====
- Uses the MesloLGL Nerd Font Mono font, which must be installed.
- `macos-option-as-alt = true` makes Option act as Alt. Remove that line if you type special characters with Option.
- For kitty graphics and extended keys inside tmux, see the matching settings in [Tmux-Config](https://github.com/i-am-david-weinstein/Tmux-Config).
